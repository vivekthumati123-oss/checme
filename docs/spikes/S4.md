# Spike S4: Commit with `GITHUB_TOKEN` vs `COMMIT_PAT`

- **Command**: Contract/design verification against Octokit GraphQL (`@octokit/graphql@8.2.2` `createCommitOnBranch`) in `src/github/commit.ts` (live Actions run pending sandbox repo token).
- **Decision**: Default to built-in `GITHUB_TOKEN` (`contents: write`, `pull-requests: write`) using `createCommitOnBranch` with `expectedHeadOid` and commit headline `test: add unit tests for <n> file(s) [unit-agent]`. Optional `commit.auth: pat` uses `UA_COMMIT_TOKEN` (`COMMIT_PAT`). Branch protection errors fall back to posting collapsed `patch.diff` and exiting 0.
