# Spike S2: Tree-sitter WASM (`web-tree-sitter` + `tree-sitter-wasms`)

- **Command**: Ran inline ESM probe with `web-tree-sitter@0.24.7` and `tree-sitter-wasms@0.1.13` across JS, TS, TSX, Python, and Java snippets on Windows `Node v26.3.0`.
- **Observed Result**:
  - `web-tree-sitter@0.24.7` initialized cleanly via `Parser.init()` and loaded all 5 grammars from `node_modules/tree-sitter-wasms/out/`:
    - `tree-sitter-javascript.wasm` (647,334 bytes) -> root `program`, `hasError: false`
    - `tree-sitter-typescript.wasm` (2,342,690 bytes) -> root `program`, `hasError: false`
    - `tree-sitter-tsx.wasm` (2,411,272 bytes) -> root `program`, `hasError: false`
    - `tree-sitter-python.wasm` (476,105 bytes) -> root `module`, `hasError: false`
    - `tree-sitter-java.wasm` (430,239 bytes) -> root `program`, `hasError: false`
  - **Verified AST Node Names**:
    - JS/TS: `function_declaration`, `generator_function_declaration`, `method_definition`, `arrow_function`, `variable_declarator`, `field_definition` (JS) vs `public_field_definition` (TS), `function_signature`, `abstract_method_signature`, `method_signature`, `binary_expression`, `ternary_expression`, `switch_case`, `for_statement`, `for_in_statement`, `while_statement`, `do_statement`, `catch_clause`, `if_statement`.
    - Python: `function_definition`, `class_definition`, `decorated_definition`, `decorator`, `if_statement`, `elif_clause`, `for_statement`, `while_statement`, `except_clause`, `conditional_expression`, `boolean_operator`, `match_statement`, `case_clause`.
    - Java: `method_declaration`, `constructor_declaration`, `class_declaration`, `enum_declaration`, `record_declaration`, `if_statement`, `for_statement`, `enhanced_for_statement`, `while_statement`, `do_statement`, `switch_label`, `switch_rule`, `catch_clause`, `ternary_expression`, `binary_expression`.
- **Bundle Note**: Total WASM assets (`tree-sitter.wasm` + 5 grammar WASMs) are copied to `dist/wasm/` by `scripts/build.mjs`, and `Parser.init({ locateFile })` resolves `tree-sitter.wasm` from `dist/wasm/` when running the bundled `dist/cli.js`.
- **Decision**: Pinned `web-tree-sitter@0.24.7` and `tree-sitter-wasms@0.1.13` in root `package.json`. Updated JS/TS extractor to handle both `field_definition` and `public_field_definition` for class-field arrow functions.
