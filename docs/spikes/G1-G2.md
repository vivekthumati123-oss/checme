# Spikes G1 & G2: Java Maven/Gradle Wrapper & JaCoCo Init Script

- **Local Environment Status**: `java`, `mvn`, and `gradle` are not installed on this workstation (`CommandNotFoundException`). Verification locally covers unit/integration tests using realistic captured logs (`fixtures/logs/`) and cross-platform CLI/wrapper resolution logic (`src/exec/exec.ts`, `src/stages/validate/runners/java/*`); multi-version Gradle/Maven execution is defined in `.github/workflows/matrix.yml`.
- **Spike G1 Decisions (Wrappers & Proxies)**:
  - `src/exec/exec.ts` resolves `./gradlew` / `gradlew` -> `gradlew.bat` and `./mvnw` / `mvnw` -> `mvnw.cmd` on Windows, falling back to `sh <script>` on POSIX when execute permission is missing (recorded in `report.notes`).
  - `buildEnv` preserves `HOME`/`USERPROFILE` and `GRADLE_USER_HOME` (so `~/.m2/settings.xml`, `~/.gradle/gradle.properties`, and caches work), honors `env.passProxy` (`HTTP_PROXY`/`HTTPS_PROXY`/`NO_PROXY`/`GRADLE_OPTS`/`MAVEN_OPTS`), and passes `env.pass` (e.g. `MVNW_REPOURL`) minus secret-regex matches.
  - Download/TLS/proxy failures (`Could not resolve`, `Could not GET`, `Connect to .* failed`, `PKIX path building failed`) classify as `environment_error` (or `wrapper_unavailable` when wrapper download fails) with host extraction and remedy guidance.
- **Spike G2 Decisions (Gradle Init Script & Multi-Module Selection)**:
  - Bundled `src/stages/validate/runners/java/jacoco-init.gradle` copied to `dist/unit-agent-jacoco.init.gradle` supports both modern Gradle (`xml.required = true`) and legacy Gradle (`xml.enabled = true`) via `try { xml.required = true } catch (MissingPropertyException e) { xml.enabled = true }`.
  - Reads optional `UA_JACOCO_VERSION` env var; binds `finalizedBy tasks.named('jacocoTestReport')` on `test`.
  - Multi-module selection uses `-p <moduleDir>` for Gradle and `-pl <moduleRel> -am` for Maven computed from the nearest ancestor containing `pom.xml`/`build.gradle(.kts)`.
