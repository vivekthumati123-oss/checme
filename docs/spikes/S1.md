# Spike S1: Copilot SDK (`@github/copilot-sdk@1.0.16`)

- **Command**: Inspected pinned `@github/copilot-sdk@1.0.16` TypeScript declarations (`dist/types.d.ts`, `dist/client.d.ts`, `dist/session.d.ts`, `dist/generated/session-events.d.ts`, `dist/generated/rpc.d.ts`) and authored `scripts/spike-sdk.ts` (supports offline contract mode and `--live` Actions mode with `COPILOT_GITHUB_TOKEN`).
- **Observed Result (from pinned package `1.0.16`)**:
  - `CopilotClientOptions` provides `mode: "empty" | "copilot-cli"`, `gitHubToken`, `useLoggedInUser: false`, `logLevel`. Setting `mode: "empty"` disables ambient CLI features and skips custom instructions (`skipCustomInstructions: true`, `customAgentsLocalOnly: true`).
  - `SessionConfigBase` provides `availableTools: ["submit_tests"]`, `excludedTools: ["builtin:*", "mcp:*"]`, `onPermissionRequest`, and `provider.maxOutputTokens`.
  - `PermissionHandler` returns `{ kind: "denied-by-rules", rules: [] }` (`PermissionDecisionDeniedByRules`) to reject all permission prompts cleanly.
  - `defineTool("submit_tests", { parameters: SubmitTestsSchema, isTerminal: true, skipPermission: true, handler })` accepts Zod schemas and ends the model turn on successful submission (`CompletionReceiptStopReason = "terminal_tool"`).
  - Truncation / stop signals exposed on `assistant.usage` event: `AssistantUsageData.finishReason` (`"stop" | "length" | "tool_calls" | "content_filter"`), `inputTokens`, `outputTokens`, `contentFilterTriggered`, plus `session.truncation` (`TruncationData`).
- **Live CI Execution Status**: Not executed live offline because `COPILOT_GITHUB_TOKEN` is absent in this environment; `scripts/spike-sdk.ts --live` is wired for sandbox Actions verification (must record exact fine-grained PAT Copilot permission name on first live CI run).
- **Decision**: `src/llm/client.ts` uses `mode: "empty"`, `availableTools: ["submit_tests"]`, `excludedTools: ["builtin:*", "mcp:*"]`, `onPermissionRequest` returning `denied-by-rules`, and detects truncation via `finishReason === "length"`, `TruncationEvent`, unparseable/incomplete arguments, or `AssistantMessageData` content fallbacks (`TruncatedOutputError`).
