# Spike G1: Java Maven/Gradle Wrapper & Proxy Support

- **Status**: Cross-platform wrapper resolution and failure classification implemented; live `java`/`mvn`/`gradle` execution not verified on this workstation (`java`, `mvn`, `gradle` not installed; multi-version Java matrix defined in `.github/workflows/matrix.yml`).
- **Findings & Decisions**:
  - `src/exec/exec.ts` resolves `./gradlew` / `gradlew` -> `gradlew.bat` and `./mvnw` / `mvnw` -> `mvnw.cmd` on Windows, falling back to `sh <script>` on POSIX when the execute bit is missing (recorded in `report.notes`).
  - `buildChildEnv` preserves `HOME` / `USERPROFILE` and `GRADLE_USER_HOME` (so `~/.m2/settings.xml`, `~/.gradle/gradle.properties`, and caches work), honors `env.passProxy` (`HTTP_PROXY`, `HTTPS_PROXY`, `NO_PROXY`, `GRADLE_OPTS`, `MAVEN_OPTS`), and passes `env.pass` (for example `MVNW_REPOURL`) minus secret-regex matches (`SECRET_ENV_KEY_RE`, `EXPLICIT_FORBIDDEN_ENV_KEYS`).
  - Download, TLS, and proxy failures (`Could not resolve`, `Could not GET`, `Connect to .* failed`, `PKIX path building failed`) classify as `environment_error` or `wrapper_unavailable` with host extraction and actionable remedy guidance.
