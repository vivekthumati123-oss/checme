# Spike S3: Optional `unshare` Network-Off Wrapper

- **Command**: Authored `scripts/run-offline.sh` (`unshare --map-root-user --net -- sh -c 'ip link set lo up 2>/dev/null || true; exec "$@"' -- "$@"`) and reviewed Linux vs Windows runner capabilities.
- **Observed Result**: Not executed natively on this Windows workstation (`unshare` is Linux-only); default config strategy remains `offline.strategy: none` (per Spec Section 1 / D12).
- **Decision**: Keep `offline.strategy: none` as default. On non-Linux hosts or when `unshare` fails self-test at runtime, `src/exec/exec.ts` cleanly falls back to `none` and records a note in `report.notes`. Reject `offline.strategy: unshare` combined with Gradle at config validation time (Section 4.1).
