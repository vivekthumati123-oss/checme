# Spike S10: `UA_NODE` Persistence Across Steps

- **Command**: Structural verification of `.github/actions/setup-agent/action.yml` and `.github/actions/cli/action.yml` (live multi-step runner verification in `.github/workflows/ci.yml`).
- **Decision**: `.github/actions/setup-agent/action.yml` captures `UA_NODE=$(node -p 'process.execPath')` into `$GITHUB_ENV` BEFORE repo toolchain setup; `.github/actions/cli/action.yml` invokes `"${UA_NODE:-node}"`.
