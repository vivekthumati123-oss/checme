# Spike G2: Gradle JaCoCo Init Script & Multi-Module Selection

- **Status**: Init script and multi-module selection design recorded; live Gradle 7/8/9 & Maven 3.8/3.9 execution not verified locally (multi-version Java matrix defined in `.github/workflows/matrix.yml`).
- **Findings & Decisions**:
  - `src/stages/validate/runners/java/jacoco-init.gradle` is copied into `dist/unit-agent-jacoco.init.gradle` during `npm run build` / `npm run build:unit-agent`.
  - Supports both modern Gradle (`xml.required = true`) and legacy Gradle (`xml.enabled = true`) via `try { xml.required = true } catch (MissingPropertyException e) { xml.enabled = true }`.
  - Reads optional `UA_JACOCO_VERSION` env var and attaches `finalizedBy tasks.named('jacocoTestReport')` on `test` tasks.
  - Multi-module selection computes the nearest ancestor containing `pom.xml` or `build.gradle(.kts)` and passes `-p <moduleDir>` for Gradle and `-pl <moduleRel> -am` for Maven.
