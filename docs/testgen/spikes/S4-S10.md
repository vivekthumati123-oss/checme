## Spike S8 — `node_modules` Link in Disposable Copy (Live Verified on Windows)
- **Command**: Created `fs.mkdtemp(os.tmpdir() + "/ua-spike-s8-")`, linked `node_modules` via `fs.symlink(src, dest, "junction")`, executed `node probe.mjs` importing `zod`.
- **Observed Result**: `S8_ZOD_OK ok` — junction creation succeeded on Windows 11 (`Node v26.3.0`) with standard user privileges and module resolution succeeded inside `os.tmpdir()`.
- **Decision**: `src/stages/validate/workspace.ts` links `node_modules`, `.venv`, and `venv` via `"junction"` on Windows and `"dir"` symlink on POSIX, with cleanup via `fs.rm(..., { recursive: true, force: true, maxRetries: 5, retryDelay: 200 })`.
